# Gender and Age Detection Using Deep Learning

## Overview

This project uses OpenCV and deep learning models to detect faces and predict the age and gender of individuals from images.

## Technologies Used

- Python
- OpenCV
- NumPy
- TensorFlow / Keras
- Jupyter Notebook
- Deep Learning
